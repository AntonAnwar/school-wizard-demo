================================================================
    إعداد المدرسة — التشغيل على جهازك الخاص
    School Wizard — how to run on your own machine
================================================================

أ) الطريقة الأسهل (بدون أي تثبيت):
   - اضغط نقرة مزدوجة على ملف  setup.html  لفتحه في متصفحك
     (Chrome أو Edge أو Firefox).
   - لا يحتاج الإنترنت ولا تثبيتًا — البيانات تُحفظ تلقائيًا
     في التخزين المحلي للمتصفح (localStorage).

ب) إن لاحظت أن البيانات لا تتشارك بين الصفحات:
   - شغّل من داخل هذه المجلد (Terminal / Command Prompt):
         python3 -m http.server 8000
   - ثم افتح:  http://localhost:8000/setup.html
   - (أو استخدم الملف المرفق:  python3 serve.py  — يخدم بلا كاش)

كيف تبدأ:
   1) من setup.html اضغط «⚡ تحميل بيانات تجريبية كاملة» لتجربة
      النظام فورًا (تعيينات تدريس كاملة + سلوكيات مسجلة +
      خطة أسبوعية منشورة)، أو امشِ على الشاشات العشر.
   2) زر «▶ أكمل من حيث توقفت» يقفزك لأول خطوة ناقصة.

الدورة اليومية (بعد الإعداد أو تحميل البيانات التجريبية):
   3) افتح portal.html واختر دورك ثم هويتك (نموذج بلا كلمة مرور).

   بدور المعلم:
   - «صفوفي» ← اضغط مربع (مادة × شعبة):
     • أنشئ واجبًا/اختبارًا وارفع ملفه بزر «📎 رفع ملف»
       ← يصل الطلاب وأولياؤهم إشعارًا فورًا.
     • قيّم التسليمات: ترى ملف إجابة الطالب (تحميل) + نصه
       ← الدرجة والملاحظة تصلان للطالب وولي الأمر فورًا.
     • تبويب «📅 الخطة الأسبوعية»: اكتب خطة الأسبوع وارفع
       ملفها إن أردت ← «إرسال الخطة والإشعار» يصل الشعبة كاملة.
     • تبويب «🧭 السلوك»: طالب ← سلبي/إيجابي ← سلوك ← ملاحظة
       ← تسجيل (يصل ولي الأمر تلقائيًا مع كل سجل).
     • «الحضور»: زر «✅ الكل حاضر» ثم عدّل الغائبين، الغياب
       بعذر يُشعر ولي الأمر تلقائيًا.
   - «ملاحظاتي»/«التسليمات»: كل ملاحظة أكاديمية أو سلوكية
     تُرسل للطالب وولي الأمر مع إشعار.

   بدور الطالب:
   - «✍️ تسليم المهمة»: ارفع ملف إجاباتك (حتى 1MB) أو اكتب
     إجابتك في المساحة — أو كليهما ← المعلم وولي أمرك يُشعران.
   - «📅 الخطة الأسبوعية»: خطط مادة/مادة بشعبتك مع تحميل الملفات.
   - «ملاحظاتي» و«⚖️ سلوكي» وكشف نتيجتي (بما فيها وضعي السلوكي).

   بدور ولي الأمر:
   - كل حدث له أثر: واجب جديد، تسليم ابنك، درجة + ملاحظة،
     ملاحظة، سجل سلوك، مرحلة تنبيه، غياب بعذر، خطة أسبوعية.
   - «📅 الخطة الأسبوعية» لابنك (كل المواد) + «⚖️ سلوك الابن»
     (بما فيها حالات المتابعة المفتوحة) + استفسار مباشرة
     من مربّي الابن كمحادثة فردية.

ملاحظات:
   - الملفات المرفوعة تُخزن في المتصفح (حتى 1MB لكل ملف).
   - «↺ مسح كل البيانات» يعيد النظام فارغًا، وزر «⚡ تحميل
     بيانات تجريبية» يستعيده. كل شاشة ملف مستقل، وكلها
     تشارك نفس قاعدة البيانات المحلية.
